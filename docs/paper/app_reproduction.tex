\section{Two-rank reproduction on V100}
\label{app:reproduction}

The precision campaign was rerun at the paper sizes with two MPI ranks per
case on a node with four V100-SXM2-32GB devices.  Each rank owned one device,
and two cases ran at a time on the disjoint pairs 0,1 and 2,3.  The binary was
built from commit \texttt{b29f55ed4ee787f19e5a74eb8bd7e3a3e84b53ed} with CUDA
12.6 for \texttt{sm\_70}, OpenMPI 4.1.6, parallel HDF5 1.10.10, ADIOS2 2.9.2
and openPMD 0.17.1.  The harness is
\texttt{docs/paper/precision-campaign/run\_campaign.py} with
\texttt{--mpi-ranks 2} and one \texttt{--gpu-pairs} entry per worker; it adds
\texttt{--fft-mode distributed} to every mesh command.  The order-12 exact
reference driver ran as a single process.  The harness regenerated the
reference for cases that define one, and the regenerated \texttt{large1} and
\texttt{hires} arrays are identical to the committed reference arrays.  The
\texttt{bdata2} comparison uses the committed reference arrays, and the line
cases use the single-process driver.
The paper campaign predates the automatic velocity-bin edge rule, so the rerun
pins \texttt{--velocity-bin-edges uniform} for every case with more than one
velocity bin.

The non-near-shell cases reproduce the committed data.  The two-rank
\texttt{line-w4b} worst relative error changes by at most
$1.3\times10^{-13}$ over all 56 rows, and \texttt{large1} changes the field by
at most $2\times10^{-10}$ of its peak.  The outer \texttt{line-gamma} ring at
$h=0.25$ is $5.3\times10^{-6}$ in the two-rank run against
$2.49\times10^{-1}$ in the committed data; the inner rings are unchanged.

The near-shell differences are confined to cases that use the host evaluator
(\texttt{--near-shell fast}).  A one-rank control on the same binary
reproduces the two-rank \texttt{hires} field to $10^{-9}$ relative, so the
differences are not an MPI decomposition effect.  The host evaluator's
conditioning at high $\gamma$ and at oblique incidence depends on the host
math library, and the paper measurements were taken on an H100 node.  We
therefore retain the H100 near-shell values as the reference and report the
V100 run as a host-sensitivity check.  The \texttt{multivel} binning curve
agrees within $1.0\times10^{-3}$ in energy and $7.1\times10^{-2}$ in the
angular coordinates; its intermediate field arrays are not a paper metric.
The archived \texttt{var1b} input is not in the repository, so that case was
not rerun.
